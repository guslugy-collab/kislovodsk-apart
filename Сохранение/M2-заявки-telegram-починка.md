# M2 — Починка заявок сайт → Telegram (Cloudflare Worker)

- **Код версии (git):** тег `M2`
- **Дата:** 2026-07-27

## Что сделано (простым языком)
Заявки с формы сайта **не доходили** в Telegram. Нашли и починили причину — теперь
цепочка **сайт → Cloudflare Worker → Telegram (бот «вершина»)** работает полностью,
включая русский текст без «кракозябр». Проверено живой тестовой заявкой — сообщение
пришло владельцу в чат бота.

## Как сделано (для ИИ)
- **Симптом:** Worker `vershina-leads` отвечал `{"ok":false,"error":"tg_400"}`. Токен при
  этом рабочий (иначе был бы `401`) → значит проблема в чате/секретах, а не в авторизации.
- **Причина:** в секрете `TG_TOKEN` (или в `TG_CHAT`) при сохранении в панели Cloudflare
  затесался лишний **пробел/перенос строки** → URL к Telegram API ломался → `400`.
- **Правка в `worker.js`:**
  - `.trim()` на `TG_TOKEN` и `TG_CHAT` в запросе к `api.telegram.org` — срезает случайные
    пробелы (страховка на будущее).
  - Worker теперь при ошибке возвращает `description` от Telegram (точный текст, напр.
    `chat not found`), а не глухое `tg_400` — чтобы диагностика была мгновенной.
  - Задеплоено через панель Cloudflare («Редактировать код» → «Развернуть»), НЕ через git.
- **Файлы:** новый `worker.js` добавлен в репозиторий; §5 и §8 в `НАЧНИ-ОТСЮДА.md` обновлены
  (форма теперь описана как «идёт через Worker», раньше ошибочно значилось «без бэкенда»).
- Коммит — **только своих файлов по путям** (`worker.js`, `НАЧНИ-ОТСЮДА.md`, снимок,
  `ИСТОРИЯ-ВЕРСИЙ.md`). `index.html` НЕ трогался — там лежала несохранённая правка
  телефон-сессии; `git add -A` не использовался.

## Нюансы, открытые на шаге
- **Кириллица в `curl` на Windows** приходит «кракозябрами» — это артефакт терминала, НЕ
  бага сайта/бота. Реальная форма шлёт из браузера правильный UTF-8. Для чистого теста через
  curl: писать JSON в файл (UTF-8) и слать `--data-binary @файл` с заголовком `charset=utf-8`.
- Бот обязан быть **«запущен»** (кнопка Start) владельцем, иначе Telegram отдаёт `chat not found`.
- Деплой Worker — только через панель Cloudflare (wrangler/node на машине не установлены).

## Как проверить
- Живой тест: `curl -X POST https://vershina-leads.usaamnesia2026.workers.dev -H "Content-Type: application/json" --data-binary @payload.json` (payload.json в UTF-8 с полями name/phone) → ждать `{"ok":true}`.
- В чат бота «вершина» (chat_id 924658134) приходит «🏔 Заявка с сайта …» с читаемым русским текстом.
- `git tag` → виден `M2`.
